# Simple Interest Calculator

A simple calculator to calculate Simple Interest.

## Formula
Simple Interest = (Principal * Rate * Time) / 100

Where:
- Principal = Initial amount
- Rate = Annual interest rate
- Time = Time period in years

## Description
This is a simple interest calculator built as part of the Getting Started with Git and GitHub course. It takes user inputs for principal, rate, and time and returns the simple interest.
